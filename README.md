## ویژگی‌ها

- **۱٬۵۳۹ سؤال واقعی** از نمونه‌آزمون‌ها؛ هیچ سؤالی ساخته یا بازنویسی نشده و منبع هر سؤال ثبت است.
- **سطح‌بندی اهمیت (سطح ۱ تا ۵):** سؤالی که در چند نمونه‌آزمون مستقل تکرار شده، همیشه سطح ۱ است.
- **آزمون شبیه‌سازی‌شده:** ۳۰ سؤال مثل آزمون اصلی، ۲۰ سؤال از فصل ۱ و ۱۰ سؤال از فصل‌های دیگر.
- **بعد از هر پاسخ:** نکتهٔ آموزشی کوتاه و صفحهٔ منبع در کتاب آموزشی؛ بعد از پاسخ غلط باز، بعد از پاسخ درست بسته.
- **وب‌اپ قابل نصب:** افزودن به صفحهٔ اصلی گوشی، اجرای بدون اینترنت و ادامهٔ آزمون نیمه‌تمام.

## اجرا روی کامپیوتر

برنامه به ساخت (build) نیاز ندارد؛ فقط باید از یک سرور ساده باز شود:

```bash
python3 -m http.server 8765
```

بعد `http://localhost:8765` را در مرورگر باز کنید.

## انتشار روی GitHub Pages

در تنظیمات مخزن: **Settings → Pages → Deploy from a branch** و شاخهٔ `main` با پوشهٔ `/ (root)`.
برنامه روی `https://mahdigraph.github.io/azmoonyar/` باز می‌شود. چون این آدرس HTTPS است، نصب روی گوشی و اجرای بدون اینترنت هم کار می‌کند.

## ساختار پروژه

| مسیر | محتوا |
|---|---|
| `index.html`، `app.js`، `styles*.css` | رابط کاربری |
| `questions.js`، `data/questions-*.js` | بانک سؤال (متن، گزینه‌ها، پاسخ و منبع هر سؤال) |
| `exam-builder.js` | ساخت آزمون از سطح‌ها و شبیه‌سازی آزمون اصلی |
| `data/question-metadata.js`، `data/question-hints.js` | سطح، منبع کتاب و نکتهٔ آموزشی هر سؤال (ساخته‌شده با اسکریپت) |
| `data/manual-review.json` | مواردی که تصمیمش با انسان است، مثل ناهمخوانی کلید با کتاب |
| `manifest.json`، `sw.js`، `pwa.js`، `icons/` | وب‌اپ قابل نصب و کار بدون اینترنت |
| `branding/` | لوگو و تصویر معرفی مخزن |
| `scripts/` | بررسی‌ها، ساخت لوگو و داده‌های مطالعه، ترمیم تصویرها و اسکریپت‌های استخراج ([راهنما](scripts/README.md)) |

## بررسی‌ها

هر دو بررسی روی همین مخزن و بدون فایل اضافه اجرا می‌شوند:

```bash
node scripts/tiering/validate_study_bank.mjs
node scripts/check_web_app.mjs
```

اولی درستی بانک سؤال را بررسی می‌کند: هر سؤال با اثر انگشت SHA-256 نسخهٔ اولیه مقایسه می‌شود، و سطح‌ها، منبع‌های کتاب و نکته‌ها کنترل می‌شوند. دومی مانیفست، آیکون‌ها و فایل‌هایی را که وب‌اپ برای کار آفلاین لازم دارد بررسی می‌کند.
ساختن دوبارهٔ سطح‌ها و منبع‌ها از اول به فایل‌های محلی نیاز دارد که در مخزن نیستند (پایین را ببینید).
لوگو و آیکون‌ها با `node scripts/build_brand_assets.mjs` از یک طرح واحد ساخته می‌شوند.

## منابع

سؤال‌ها از نمونه‌آزمون‌های منتشرشده جمع‌آوری شده‌اند و منبع‌ها به کتاب آموزشی هنرجویان پایهٔ سوم اشاره می‌کنند. فایل‌های PDF و متن کامل کتاب در مخزن نیستند؛ برنامه فقط جملهٔ مرتبط کتاب را کنار هر سؤال نشان می‌دهد. سطح‌ها اولویت مطالعه‌اند، نه احتمال رسمی آمدن سؤال در آزمون.
