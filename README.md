- **۱٬۵۳۹ سؤال واقعی** از نمونه‌آزمون‌ها؛ هیچ سؤالی ساخته یا بازنویسی نشده است.
- **سطح‌بندی اهمیت** و **آزمون شبیه‌سازی‌شدهٔ ۳۰ سؤالی** مثل آزمون اصلی.
- **نکتهٔ آموزشی و منبع کتاب** بعد از هر پاسخ.
- **وب‌اپ قابل نصب** روی گوشی و کامپیوتر؛ بدون اینترنت کار می‌کند و آزمون نیمه‌تمام را ادامه می‌دهد.

## اجرا

```bash
python3 -m http.server 8765
```

بعد `http://localhost:8765` را باز کنید. بررسی‌ها و اسکریپت‌ها در [راهنمای اسکریپت‌ها](scripts/README.md) آمده‌اند.

## منابع

سؤال‌ها از نمونه‌آزمون‌های منتشرشده و منبع‌ها از کتاب آموزشی هنرجویان پایهٔ سوم است. فایل‌های PDF و متن کامل کتاب در مخزن نیستند. سطح‌ها اولویت مطالعه‌اند، نه احتمال رسمی آمدن سؤال در آزمون.
